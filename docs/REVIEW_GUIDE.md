# Hướng dẫn trình bày EX12–15

Chạy `npm start`, chọn bài trong menu rồi demo và đọc component tương ứng.

## Bài 12 useState

Bảy bài nhỏ minh họa state cục bộ và cập nhật giao diện.

Chạy từng demo theo thứ tự 1–7. Kéo Item 1 xuống Item 3 rồi dùng nút lên/xuống. Mục useRef là phần bổ sung từ code ban đầu.

Đọc: [README bài 12](../src/exercises/exercise-12/README.md).

## Bài 13 useEffect

Fetch theo prop, timer, resize listener và validation theo dependency.

Đổi user 1 → 2, xem loading và dữ liệu mới. Chờ timer về 0, restart. Resize cửa sổ. Nhập ab rồi abc vào validation. Đổi bài để kiểm tra cleanup.

Đọc: [README bài 13](../src/exercises/exercise-13/README.md).

## Bài 14 useContext

ThemeProvider và CartProvider chia sẻ dữ liệu giữa component.

Toggle Theme hai lần. Thêm Uthappizza hai lần và Zucchipakoda một lần: 3 món, $11.97. Remove Uthappizza rồi Clear Cart.

Đọc: [README bài 14](../src/exercises/exercise-14/README.md).

## Bài 15 useReducer

Reducer counter và ngân hàng câu hỏi với action rõ ràng.

Tăng/giảm/reset counter. Chọn Canberra và Mars để được 2/2. Restart rồi chọn sai để kiểm tra score.

Đọc: [README bài 15](../src/exercises/exercise-15/README.md).
